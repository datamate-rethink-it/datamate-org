Sicherer Datenaustausch mit unserer Dropbox-Alternative

Dropbox gehört weltweit zu den populärsten Cloud-Anbietern. Dies kommt nicht von ungefähr, den mit wenigen Klicks ist ein Account angemeldet und ein paar Gigabyte an Speicherplatz stehen für die eigenen Daten zur Verfügung. Das Teilen von Daten ist ähnlich einfach und auch die Desktopsoftware sorgt für eine zuverlässige Synchronisation von dem eigenen Rechner und dem amerikanischen Cloud-Dienst.
In letzter Zeit machte Dropbox jedoch vermehrt durch negative Schlagzeilen auf sich aufmerksam: Fragwürdige Sicherheitsmechanismen, die bereitwillige Weitergabe von unverschlüsselten Nutzerdaten an die US-Regierung oder die Bestellung der vehementen Befürworterin der Total-Überwachung Condoleezza Rice in den Dropbox-Vorstand sind nur die Spitze des Eisbergs.

Höchste Zeit also sich nach einer sicheren Alternative umzusehen. Die Anforderungen sind dabei klar umrissen: die Lösung ist nur dann eine echte Dropbox-Alternative, wenn diese genauso komfortabel und zuverlässig ist, jedoch die eigenen Daten nicht in irgendwelchen anonymen Rechenzentren von amerikanischen Firmen gespeichert werden. Das Teilen von Daten muss bequem über eine Weboberfläche an beliebige Personen möglich sein und die Lösung sollte neu hinzukommende Dateien oder Dateiänderungen in Sekunden mit dem Server synchronisieren.

All diese Anforderung meistert Fellow mit Bravur. Dank der von uns eingesetzten Software Seafile wird dieser Small Business Server zur perfekten Dropbox-Alternative und bietet die bekannten und beliebten Fähigkeiten ohne die damit verbundenen Nachteile. Im Gegenteil, die Vorteile im Bereich der Sicherheit sind dramatisch. Anstatt die eigenen Daten aus der Hand zu geben und irgendjemanden anzuvertrauen, werden die Daten auf dem eigenen Server im eigenen Büro oder auf einem angemieteten virtuellen Server gespeichert. Die Freigabe an Geschäftspartner ist natürlich trotzdem möglich.

Warum eine Dropbox-Alternative auf einem eigenen Server im eigenen Büro?

Auch wenn Cloud aktuell in aller Munde ist, sollte sich jeder Unternehmer genau überlegen, ob es Sinn macht die eigenen geschäftskritischen Daten so leichtfertig aus der Hand zu geben. Mit Fellow, dem Small Business Server von datamate erhalten Sie einen standardisierten Business Server der Marke Terra für Ihr Büro. Das Einstecken des Strom- und Netzwerksteckers genügen – alles weitere übernehmen die Experten von datamate per Fernwartung.

So erhalten Sie das Beste aus beiden Welten. Die Sicherheit eines eigenen Servers, den nur Sie unter Kontrolle haben. Es gibt keine Hintertürchen oder US-Regierungen, die Zugriff einfordern können. Wenn Sie den Stecker ziehen, sind Ihre Daten aus dem Internet verschwunden.

Gleichzeitig kriegen Sie zum Festpreis eine etablierte, zuverlässige und sofort einsetzbare Lösung, die auch höchsten Ansprüchen gerecht wird. Die eingesetzte Software Seafile ist eine Open Source-Software, die von einer kommerziellen chinesischen Firma entwickelt wird. Die Lösung ist dabei so ausgereift, dass sogar die beiden Hochschulen HU Berlin und JGU Mainz diese Lösung für alle Ihre Studenten verwenden. In Summe nutzen alleine an diesen beiden Hochschulen mehrere tausend Studenten täglich die gleiche Softwarelösung, wie Sie bei unserer Dropbox-Alternative zum Einsatz kommt und tauschen Gigabyte an Daten aus.

Dabei ist Seafile nicht die einzige vorkonfigurierte Softwarelösung auf Fellow. Neben der sicheren Datenaustauschplattform erfüllt Fellow sämtliche Anforderungen von kleinen und mittelständischen Unternehmen.
