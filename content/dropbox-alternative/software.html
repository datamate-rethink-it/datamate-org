Seafile – die perfekte Dropbox-Alternative

Auf jedem Fellow installieren wir die Software Seafile, welche Fellow zu einer perfekten Dropbox-Alternative macht. Die Funktionsweise von Seafile ist dabei vergleichbar mit der von Dropbox. Es gibt einen zentralen Serverdienst mit einem zugehörigen Speichervolumen und es gibt für jedes Betriebssystem und für alle mobilen Geräte eine Client-Software, die für die Synchronisation der Daten sorgt. Freigaben werden über die Weboberfläche des Serverdienstes erteilt und auch der Online-Papierkorb kann über den Browser eingesehen werden.

Wie funktioniert die Synchronisation?

Für jedes Betriebssystem gibt es ein kleines Softwarepaket, welches installiert und konfiguriert werden muss. Danach überwacht die Software beliebige Ordner auf der lokalen Festplatte. Sobald eine Datei verändert oder eine neue Datei gespeichert wird, wird eine Kopie der Datei zum Seafile-Server geschickt. Bei Änderungen werden nur die Änderungen übertragen, so dass auch bei großen Dateien keine großen Dateimengen übertragen werden müssen. Sobald die Datei auf dem Server ankommt, wird die Datei auch an alle weiteren verbunden Clients synchronisiert. So kann man beliebig viele Rechner, Notebooks, Tables oder Notebooks synchron halten. Bei entsprechender Einstellung von Seafile ist auch eine Synchronisation über einen sicheren VPN-Kanal oder direkt über das Internet möglich. So hat man egal von welchem Internetzugang immer Zugriff auf den aktuellen Datenbestand.

Freigabe an Mitarbeiter oder Teammitglieder

Natürlich muss man manchmal seine Daten auch mit anderen teilen. Die Software Seafile macht diesen Vorgang denkbar einfach. Man kann eigene Ordner lesend oder schreibend an andere Personen freigaben. Diese Personen können danach auf diese Dateien zugreifen und über die Client-Software auch mit jedem Computer synchronisieren. So sind Arbeitsteams in wenigen Minuten angelegt und können dann gemeinsam an den Dateien arbeiten und darauf zugreifen.

Wie zuverlässig ist Seafile?

Seafile ist eine absolute zuverlässige und professionelle Software und ein adequater Dropbox-Ersatz. Seafile wird von einer chinesischen Firma entwickelt und existiert in zwei Versionen. Es gibt eine kostenloses Community Version mit eingeschränkten Funktionen sowie eine lizenzpflichtige Business Variante. Die wichtigsten Funktionsunterschiede liegen im Bereich Clusterfähigkeit, Zugriffslogging, Dokumentensuche und -vorschau über die Weboberfläche. Dies sind alles Fähigkeiten, die für unseren Einsatz als Dropbox-Alternative und sichere Datenaustauschplattform auf Fellow, unserem Small Business Server, keine wichtige Rolle spielen. Somit ist die kostenlose Community Variante auf jedem Fellow installiert.

Seafile ist in Europa zwar noch nicht so verbreitet wie das bekanntere owncloud, jedoch konnte Seafile schon zwei große Universitäten für sich gewinnen. Seit September 2015 läuft der neue Cloud-Speicher der Universität Mainz und jeder Student hat Zugriff auf 20 Gigabyte an Seafile-Speicherplatz. Auch die TU Berlin nutzt Seafile um Ihren Studenten eine Datenspeicher- und Datenaustauschplatt zu bieten. Seafile ist somit eine zuverlässige Software, die auch in großen Installationen mit mehreren Petabyte an Daten zurechtkommt. Dies bestätigt uns darin, dass Seafile die richtige Software für unsere Dropbox-Alternative auf Fellow ist.
