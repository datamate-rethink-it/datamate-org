Windows 10

Das aktuellste Windows System installieren – Windows 10 installieren

Wahl der Architektur

Nach der Auswahl der Windows 10 all-in-one ISO muss zunächst die Architektur der Neuinstallation von Windows 10 ausgewählt werden.

Systemstart

Nun lädt der Rechner die notwendigen Dateien und Treiber. Das kann einige Augenblicke dauern.

Sprachwahl

Los geht die Windows Neuinstallation mit der Auswahl der Sprache, Zeitzone und Tastaturlayout bzw. Eingabemethode. Das kennt man bereits so aus dem Windows Setup früherer Windows Versionen.

Installationsstart

Zur Installation geht’s mit Klick auf Jetzt installieren. Zu den erweiterten Reparaturoptionen kommt man über die Schaltfläche Computerreparaturoptionen unten links. Auch das kennt man exakt so von älteren Windows Betriebssystemen.

Start des Setups

Nach diesen vorbereitenden Maßnahmen startet nun das Windows Setup. Das Windows Setup ist das Programm, das die Windows Installation auf Deinem Rechner ausführt.

Aktivierung

Die Windows 10 Neuinstallation wird durch die Eingabe eines gültigen Product Keys aktiviert. Die Windows Aktivierung ist bei Windows 10 an diese frühe Stelle des Installationsprozesses gerutscht. Wenn Windows 10 nur testweise neuinstalliert wird, dann kann man mit Ich habe keinen Product Key mit der Neuinstallation ohne Eingabe eines Keys fortfahren. In dem Fall lässt sich Windows 10 für 30 Tage ohne Einschränkung nutzen. Wenn Windows 10 gefällt, dann muss man später einen Aktivierungskey nachtragen.

Installationsart

Wenn das Windows Setup bereits eine Windows Installation auf dem Datenträger findet, dann bietet er die Auswahl zwischen Upgrade und Benutzerdefiniert an. Für eine Neuinstallation ist die zweite Auswahl die richtige. Bei einem jungfläulichen Speichermedium unterdrückt der Windows Installer dieses Fenster und springt direkt zum nächsten Schritt.

Systempartition

Installierst Du Windows 10 auf einer Festplatte, auf der noch keine Partitionen angelegt wurden, dann erscheint der gesamte Speicherplatz der Festplatte als nicht zugewiesener Speicherplatz (so wie in der Abbildung). Eine Systempartition für die Installation von Windows 10 ist schnell angelegt: Ein Klick auf Neu lässt ein zusätzliches Eingabefeld im Fenster des Assistenten erscheinen. Gebe dort die Größe der neuen Partition ein und bestätige dies mit Übernehmen. Daraufhin wird die Partition in der gewünschten Größe angelegt. Noch einfacher ist es, die ganze Partitionierungsarbeit dem Windows Setup zu überlassen – gerade für Nicht-Experten eine interessante Option. Das Windows Setup erstellt dann automatisch in dem nicht zugewiesenen Speicherplatz eine Systempartition und evtl. weitere Partitionen. Um die Automatik zu nutzen, klicke einfach auf Weiter.

Sind bereits Partitionen von einer früheren Windows Installation vorhanden, so können auch diese wiederverwendet werden. Wähle dann die alte Systempartition (C:\) als Installationslaufwerk aus. Systempartitionenen müssen immer auf einer primären Partition liegen. Natürlich lassen sich die bestehenden Partitionen auch über die Schaltflächen löschen. Gerade dann, wenn Du die bestehenden Partitionen ändern willst, macht das an dieser Stelle Sinn.

Systempartitionierung

Wenn im vorhergehenden Schritt gar keine oder nur eine Partition angelegt wurde, dann weist das Windows Setup im Rahmen der Neuinstallation von Windows 10 darauf hin, dass ggf. weitere Partition angelegt werden können. Bestätige dies mit OK.

Bestätigung der Partitionierung

Wenn das Installationsmedium den MBR-Partitionierungsstil verwendet – wie dies der datamate Hero tut -, dann legt das Windows Setup eine zusätzliche Partitionen mit Bezeichnung System-reserviert an. (Bei GPT-Installationsmedien werden zwei zusätzliche Partitionen angelegt.) Auf dieser liegen der Bootmanager und das Wiederherstellungsystem Windows RE. Puristen können diese Partition theoretisch entfernen. Wir raten aber davon ab. Die zusätzliche systemseitig angelegte Partition belegt zum einen nicht viel Speicherplatz und bietet zum anderen durchaus nützliche Funktionen. Zum Abschluss der Partitionierung werden die angelegten Partitionen nochmals angezeigt und bedürfen einer Bestätigung. Die erfolgt mit Weiter.

Installationsfortschritt

Während der Neuinstallation von Windows 10 auf dem Systemdatenträger hält Dich der Assistent über den Fortschritt der Installation auf dem Laufenden. Wenn Windows 10 auf einer SSD installiert wird, dann sollte dieser Installationsschritt in weniger als 10 Minuten abgeschlossen sein. Bei älteren Systemen kann es deutlich länger dauern.

Nach dem Abschluß der Neuinstallation startet der Rechner neu und nimmt letzte Schritte für die Inbetriebnahme von Windows 10 vor. Diese letzten Schritte der Neuinstallation können auch auf schnellen Rechnern ein paar Minuten dauern. Im Anschluss daran muss noch ein Nutzerkonto angelegt sowie die Datenschutzeinstellungen inkl. der Konfiguration der Sprachassistentin Cortana vorgenommen werden. Dann ist Windows 10 betriebsbereit.
