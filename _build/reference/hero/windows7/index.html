Windows 7

Den Klassiker unter den aktuellen Windows Betriebssystemen installieren – Windows 7 installieren

Systemstart

Nach der Auswahl der Windows 7 all-in-one ISO lädt der Computer die notwendigen Dateien und Treiber. Das dauert einige Augenblicke.

Sprachwahl

Los geht die Windows Neuinstallation mit der Auswahl der Sprache, Zeitzone und Tastaturlayout bzw. Eingabemethode.

Installationsstart

Zur Installation geht’s mit Klick auf Jetzt installieren. Zu den erweiterten Reparaturoptionen kommt man über die Schaltfläche Computerreparaturoptionen unten links.

Start des Setups

Nach diesen vorbereitenden Maßnahmen startet nun das Windows Setup. Das Windows Setup ist das Programm, das die Windows Installation auf Deinem Rechner ausführt.

Editionswahl

Voilà, das Windows Setup. Im ersten Schritt muss die Windows Edition angegeben werden, die installiert werden soll. Jede Edition taucht in dieser Liste zweimal auf, da jede Edition als 32 und 64 Bit Edition existiert.

HINWEIS: Windows Lizenzen sind nicht nur versions-, sondern auch editionsgebunden. Mit einem vorliegenden Product Key kann man nur eine Edition aktivieren und damit dauerhaft nutzen.

Lizenzbedingungen

Die Lizenbedingungen müssen akzeptiert werden, um fortzufahren.

Installationsart

Wenn das Windows Setup bereits eine Windows Installation auf dem Datenträger findet, dann bietet er die Auswahl zwischen Uprade und Benutzerdefiniert an. Für eine Neuinstallation ist die zweite Auswahl die richtige. Bei einem jungfläulichen Speichermedium unterdrückt der Windows Installer dieses Fenster und überspringt diesen Schritt.

Systempartition

Wird Windows 7 auf einer neuen Festplatte installiert, dann sind auf dieser noch keine Partitionen vorhanden. An Stelle von Partitionen wird nur nicht zugewiesener Speicherplatz angezeigt (siehe Abbildung). Das Anlegen einer Partition ist denkbar einfach: Nach dem Klick auf Neu erscheint ein zusätzliches Eingabefeld für die größe der Partition. Gebe die gewünschte Größe ein und bestätige die neue Partition mit Übernehmen. Daraufhin wird die neue Partition in der gewünschten Größe angelegt. Noch einfacher ist es bei einem jungfräulichen Datenträger, die Partitionskonfiguration komplett dem Windows Setup zu überlassen. Das Windows Setup erstellt dann automatisch eine Systempartition und evtl. weitere benötigte Partitionen. In dem Fall klicke einfach auf Weiter.

Sind bereits Partitionen von einer früheren Windows Installation vorhanden, so können diese wiederverwendet werden. Dann sollte die alte Systempartition (C:\) als Installationslaufwerk ausgewählt werden. Dies ist immer eine primäre Partition. Alternativ können über die Schaltflächen die bestehenden Partitionen gelöscht werden. Dies bietet sich insbesondere dann an, wenn die bestehenden Partitionsgrößen geändert werden sollen.

Systempartitionierung

Wenn im vorhergehenden Schritt gar keine oder nur eine Partition angelegt wurde, dann weist das Windows Setup im Rahmen der Windows Neuinstallation darauf hin, dass ggf. weitere Partition angelegt werden können. Dies einfach mit OK bestätigen.

Bestätigung der Partitionierung

Tatsächlich legt das Windows Setup bei Neuinstallationen von MBR-Installationsmedien in aller Regel eine zusätzliche Partionen mit einer Größe von 500MB an. (Bei Installationen von von GPT-formatierten Datenträgern zwei Partitionen mit einer Speicherplatz von 450MB und 100MB.) Auf dieser Partition liegt der Bootmanager und das Wiederherstellungssystem Windows RE. Unsere Empfehlung ist, im Interesse der Simplizität (Standardinstallationen sind immer einfacher zu verwalten als exotische) und für die Beibehaltung der Wiederherstellungsoptionen diese Partitionen zu erstellen. Die durch das Windows Setup angelegten Partitionen werden dann nochmals angezeigt und müssen bestätigt werden. Mit Klick auf Weiter …

Installationsfortschritt

… startet die Windows Installation. Der graphische Assistent hält Dich dabei über den Fortschritt auf dem Laufenden. Die Installation dauert auf einem aktuellen Rechner mit einer SSD als Systemdatenträger rund 10 Minuten. Bei älteren Systemen deutlich länger.

Installation abgeschlossen

Die Installation ist abgeschlossen! Nun muss der Rechner neu gestartet werden. Beim ersten Neustart werden noch Funktionen konfiguriert und ein Benutzer muss angelegt werden. Dann steht die Neuinstallation Windows 7 zur Verfügung.

Auch wenn Windows 7 neu installiert ist, es ist nicht zwangsläufig auf dem neuesten Stand. Nach jeder Neuinstallation sollten daher schnellstmöglich Windows Updates eingespielt werden. Beim recht alten Windows 7 kann dies durchaus etwas Zeit in Anspruch nehmen.

Auf Hero sollten die meisten Updates seit dem Erscheinen von Service Pack 1 enthalten sein. Wenn Du ein anderes Installationsmedium verwendest, dann kann das Convencience Roll-Up Pack zur Beschleunigung der Aktualisierung gute Dienste leisten.
