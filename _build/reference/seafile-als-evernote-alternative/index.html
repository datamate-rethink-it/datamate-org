Seafile – die sichere private Evernote Alternative

Seafile – die sichere private Evernote Alternative

  • 29. November 2016

Im Artikel OpenSource Notizdienste im Vergleich zu Evernote haben wir sechs OpenSource Notiz-Lösungen auf ihre Businesstauglichkeit getestet. Im Vordergrund stand die Frage, ob sich unter den Testobjekten eine echte Evernote Alternative befindet. Am Ende hat uns kein Dienst vollends überzeugen können. Entweder erfüllten die Lösungen die von uns definierten Kriterien nicht oder die Dienste konnte von der Usability nicht überzeugen.

Auf der weiteren Suche nach einer attraktiven Notiz-Lösung für unseren ionas-Server haben wir noch eine andere Software gefunden, die – obwohl originär keine Notizlösung – das Zeug zum ernstzunehmenden Evernote Herausforderer hat. Denn auch ohne seine Daten auf die Server von Evernote zu legen, kann man mit ihr plattformübergreifend und von überall Notizen verwalten, diese mit anderen Teilen und auch offline bearbeiten. Die Lösung, von der wir sprechen, heißt Seafile. Eigentlich eine private Dropbox-Alternative, bietet sie alle notwendigen Fähigkeiten für einen vollwertige Evernote Ersatz.

Warum Evernote so beliebt ist

Mit Evernote kann man schnell und einfach Notizen, Gedanken, Bilder, Links oder Protokolle erfassen. Dank Apps für die verschiedenen Betriebssysteme und der Sharing-Funktion kann man die eigenen Notizen unkompliziert mit Dritten teilen und gemeinsam bearbeiten.

Evernote punktet mit einer schlichten und trotzdem leistungsfähigen Oberfläche, die den Fokus auf die Erfassung der eigenen Gedanken legt.

Evernote ist für die private Nutzung kostenlos, bietet jedoch auch die kostenpflichtigen Vertragsmodelle “Plus” für 29,99 € und “Premium” für 59,99 € pro Jahr. Während die kostenlose Basic Variante nur online genutzt werden kann, erhält man mit “Plus” einen Offline-Modus und die Fähigkeit, E-Mails an Evernote weiterleiten zu können. Die “Premium” Variante ist für die Anwender interessant, die ihre Notizen, Office- und PDF-Dateien durchsuchen wollen und einen Verlauf ihrer Notizen benötigen.

Evernote ist mit Sicherheit eine feine Sache. Größter Kritikpunkt für uns ist jedoch die Abhängigkeit von einem kommerziellen Dienstleister, der sämtliche Daten in seinen Rechenzentren speichert. Mit dem Absegnen der AGBs stimmt man dabei auch den Datenschutzbestimmungen zu, die Evernote die Verwendung von Cookies, Tracking-Pixeln und ähnlichen Technologien erlaubt.

Für viele mögen diese Zugeständnisse an Evernote in Ordnung gehen, für uns als Datenschutz Apostel und Anhänger der privaten Cloud sind diese Zugeständnisse inakzeptabel. Mit Seafile als Open Source Evernote Alternative muss man es auch nicht mehr!

Wie kann Seafile eine Evernote Alternative sein?

Markdown ist eine einfache Auszeichnungssprache, um Texte leicht lesbar zu machen.

Seafile bietet eine vernachlässigte Fähigkeit, die die Software zu einer interessanten Evernote Alternative macht. Das Stichwort hier heißt Markdown. Markdown ist eine Auszeichnungssprache, mit deren Hilfe sich Texte sehr einfach strukturieren und formatieren lassen. Alle Formatierungen werden durch die Eingabe von wenigen Symbolen erreicht. Markdown bietet dafür einfache Formatierungen wie Überschriften, Listen, Links oder Quelltexte. Wenn man beispielsweise vor einem Wort oder Satz einen Stern stellt, führt das zu *fetter Schrift*. Ein # am Anfang der Zeile kennzeichnet eine Überschrift. So lassen sich mit Markdown schnell ansprechend strukturierte Texte erstellen. Nun zurück zum Anfang des Absatzes: Seafile unterstützt Markdown.

Auch dieser Artikel wurde zuerst in Markdown gedraftet, bevor er am Ende per Copy-Paste in WordPress übernommen wurde.

Beispiel: Ein Protokoll mit Markdown

Angenommen Sie schreiben auf Ihrem Notebook die folgende **Notizen.md** Datei und speichern diese in einem Ordner, der mit Seafile synchronisiert wird.

# Protokoll 
Teilnehmer: Christoph, Ralf, Oliver
Datum: 10.10.2016

## Thema 1: Mittagessen
Optionen waren:
- Thai
- McDonalds
- Pizza
Entscheidung: Thai

## Thema 2: xxx
...

Markdown Dateien können entweder direkt im Webbrowser oder in einem einfachen Texteditor bearbeitet werden.

Dank Seafile ist diese Datei sofort auf allen angeschlossenen Geräten verfügbar und kann auf jedem beliebigen Gerät weiterbearbeitet werden. Seafile bietet Clients für alle wichtigen Plattformen. Dank Favoriten-Auswahl ist die Datei auf den mobilen Geräten immer schnell im Zugriff. Seafile bietet auch Offline-Support, so dass man z.B. erste Gedanken auf dem Tablet oder Smartphone offline draftet, um diese zu einem späteren Zeitpunkt mit dem Server zu synchronisieren. Das geringe Datenvolumen der Markdown-Textdateien sorgt dafür, dass man auch bei schlechten Internetverbindungen schnell an die benötigten Daten kommt bzw. geänderte Daten an andere weitergibt.

Die Freigabe von Markdown-Dateien an andere Personen ist mit Seafile ebenfalls denkbar einfach. In der Weboberfläche einfach den entsprechenden Nutzer angegeben, fertig. Noch besser: Freigaben können mit read-only oder read-write Berechtigungen erfolgen. So lassen sich z.B. Protokolle nur mit Lesezugriff an Geschäftspartner und auch zur Bearbeitung an Kollegen freigeben.

Wer denkt, dass das Textformat von MD-Dateien keine Integration von Bildmaterial erlaubt, der unterschätzt das Potenzial des Markdown-Formats. Wenn Bilder im gleichen Seafile-Ordner liegen, können diese Bilder direkt mit einer einfachen Referenz eingebunden werden. Für die unten abgebildete Notiz ist dieser Code nötig: 

Auch Bilder können mit Markdown ganz einfach eingebunden werden...

Datenhoheit dank Seafile – die sichere Evernote Alternative

Notizen, Protokolle oder ToDo-Listen lassen sich mit Hilfe von Markdown schnell und unkompliziert erfassen. Seafile sorgt für die zuverlässige Synchronisation über alle Plattformen hinweg und erlaubt die komfortable Freigabe der Notiz-Dateien an andere Seafile-Benutzer oder externe Dritte.

Bei Anwendung der Beurteilungskriterien, die wir bei der Evaluierung anderer Open Source Evernote Konkurrenten herangezogen haben, schneidet Seafile sehr gut ab. Seafile erfüllt die fünf Kriterien, die wir an die anderen Open Source Notizdienste für Unternehmen und anspruchsvolle Privatpersonen gestellt haben.

Interesse? Probieren Sie es aus! Wir sind überzeugt, dass Sie die Einfachheit von MD und Seafile überzeugend finden werden. Seafile wird meistens für der Aufbau von privaten Clouds genutzt. In dieser Form lässt sich eine echte self hosted Evernote Alternative bauen. Wem die Datenhoheit weniger wichtig ist, findet auch Cloud-Dienste auf Basis von Seafile (z.B. YourSecureCloud).

Haben Sie bereits Seafile mit Markdown Dateien genutzt? Schreiben Sie uns Ihre Meinung. Wir würden gerne wissen, was Sie denken: Ist Seafile mit Markdown eine Evernote Alternative oder nicht?
